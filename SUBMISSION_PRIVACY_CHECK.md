# Submission Privacy Checklist

This competition package is intentionally narrower than the development repository.

Excluded from the package:

- Git history and commit metadata;
- development / architecture / acceptance evidence documents;
- test evidence containing machine-specific runtime identifiers;
- local environment files;
- API keys, tokens, passwords and private keys;
- database dumps and runtime logs;
- personal email, phone number and account profile information;
- machine-specific home-directory paths and private host addresses.

Included configuration is template-only. `.env.example` contains no provider secret.
